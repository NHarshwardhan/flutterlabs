SDK

Dart SDK archive

Download the stable SDK for your OS and unzip it into ~/dev/dart-sdk.

https://dart.dev/get-dart/archive
  1. Extract the SDK. Keep the folder path short and without spaces: ~/dev/dart-sdk.
  2. Put dart on your PATH so the terminal can find it from any folder.
  3. Install VS Code and the official Dart extension.
  4. Create a project with Cmd/Ctrl + Shift + P → Dart: New Project.
  5. Choose Console application → pick a destination folder → type a name → Enter.
  6. Open lib/, add a .dart file, and you are ready for Step 1.

final vs const

Both stop reassignment. const must be known before the program runs.

Why String? and that !?

readLineSync() returns null when the input ends (Ctrl + D / Ctrl + Z). String? says "may be null". The ! is you promising it is not — if you are wrong, the program crashes with a clear null-check error. double.parse() then converts the text to a number.

×
Two crashes worth causing

Type abc for the price → FormatException. Press Ctrl+D at the name prompt → null check fails. Both are normal, both are fixable with a try/catch later in the course.

i
break vs. continue

break leaves the loop completely. continue skips only the current round — that is why 3 is missing from 0 1 2 4 but the loop keeps going.

i
Operator cheat

&& both must be true · || at least one · ! flips it. stock-- is shorthand for stock = stock - 1.

Arrow functions

int add(int a, int b) => a + b; is the short form of { return a + b; }. Use it when the body is a single expression.

i
Scope

tax is declared at the top level, so every function can read it. x exists only inside test() — typing print(x) in main() is a compile error.

!
Analyzer hints, not bugs

dart:io is not used here, and show() returns a hard-coded string while ignoring msg. Both are harmless hints from the Dart analyzer — a good habit is to keep the file clean of them.

▶

Challenges

Close the laptop lid only after these run. Hints are deliberately small.

01 · WARM-UP Price tag

Declare a product name, a price and a quantity. Print one line: 2 × Keyboard = $91.98 — exactly two decimals.

Hint toStringAsFixed(2) and string interpolation with $.

02 · CONTROL FLOW Stock alert

Given int stock, print In Stock when it is above 10, Low Stock between 1 and 10, and Out of Stock at zero — using a ternary for the first split and an if/else if for the rest.

Hint Wrap the ternary in the else branch, or just use the ladder. Both are correct.

03 · SWITCH Fix the catalogue

Rewrite the switch with the correct spelling Electronics, add a Groceries case, and prove the default branch fires for an unknown category.

Hint Change the string in both the variable and the case, or nothing matches.

04 · FUNCTIONS Checkout maths

Write double lineTotal(double price, int qty) and double withTax(double amount) using =>. Print a bill with the subtotal, 5% tax and grand total.

Hint Reuse the global tax = 5 from Step 5. Format only the final print.

05 · OOP A real Product class

Give Product a private _price, a getter, a setter that rejects values below zero, and showDetails(). Create two products and try to set one price to -10.

Hint The setter guards; the getter exposes. Test that the bad value was ignored.

06 · LIBRARIES One more file

Move your checkout functions into lib/checkout.dart, import them into main.dart, and print a bill for two different products.

Hint Relative import: import './checkout.dart';.

Errors you will meet again

Expected ';'

A statement is missing its terminator. Look at the line the error points to and the one before it.

Null check operator used on a null value

readLineSync() returned null (end of input) and you forced it with !.

FormatException

double.parse("abc"). The text is not a number — validate before parsing.

The class … is abstract…

You tried to create the parent. Create a child that extends it instead.
