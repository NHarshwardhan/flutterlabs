00

Set up macOS

SDK, PATH, Java and an emulator that actually launches. Do this once, correctly.

Requirement

Java 17

Android Studio and Gradle need a JDK. Install Temurin 17, or point Flutter at the JDK bundled with Android Studio.

https://adoptium.net/
SDK

Flutter for ARM64

On M1 / M2 / M3 download flutter_macos_arm64-stable.zip from the manual installation section.

https://docs.flutter.dev/get-started/install/macos
Target

Android Studio

Gives you the Android SDK, the emulator and a working JDK. Xcode is only needed if you also build for iOS.

https://developer.android.com/studio
!
Apple Silicon only

The arm64 zip is for M-series Macs. On an Intel Mac download flutter_macos-stable.zip instead — the rest of the steps are identical.

  1. Install Java 17 with brew install --cask temurin@17, then confirm with java -version.
  2. Download the SDK. On the install page open Manual installation and take flutter_macos_arm64-stable.zip.
  3. Unzip it. Finder → Downloads → double-click the zip. You get a folder named flutter.
  4. Move it somewhere permanent. The recommended home is ~/development/flutter.
  5. Add it to your PATH so the flutter command works in every terminal window.
  6. Reload the shell and verify with flutter --version.

Android Studio, emulator and the JDK

Flutter needs a device. An Android emulator is the fastest one to set up on a Mac.

  1. Install Android Studio and let it finish the setup wizard (it downloads the Android SDK).

  3. Start the emulator, then confirm Flutter can see it with flutter devices.

Which JDK path?

Use the one that exists on your Mac. Android Studio ships its own: /Applications/Android Studio.app/Contents/jbr/Contents/Home. flutter doctor -v prints the path Flutter is currently using. 03

Images, from the web and from disk

One widget, two sources. The only difference is where Flutter reads the bytes from.

A. Image from a URL

Nothing to download, nothing to register — point NetworkImage at a URL and the image loads when the widget is first built.

Run itflutter run
9:41▮▮▮
Dashboard
Android · lockup.png
What you see
What happens

The image keeps its own size

There are no width or height values, so the Image asks for the file's natural size and centres it. Uncomment the two properties to force 250 × 250 — Flutter scales the picture to fit.

i
Shortcut constructors

Image.network(url) and Image.asset(path) are the compact forms of Image(image: NetworkImage(url)) and Image(image: AssetImage(path)). Same widget, less typing.

!
No internet, no picture

A network image needs a connection and a reachable URL. If the emulator shows nothing, check the URL in a browser first — and remember emulators sometimes need a moment after boot to get network access.

B. Image from your project (an asset)

Files bundled with the app. They work offline, load instantly, and must be declared in pubspec.yaml before Flutter will ship them.

  1. Create an images folder at the root of the project — next to lib, not inside it.
  2. Copy an image into it, for example plane1.png. Keep the name lowercase and exact.
  3. Declare the folder in pubspec.yaml under flutter: → assets:. Note the two-space indent and the trailing slash on the folder name.
  4. Run flutter pub get (or click Pub get in the IDE) so the asset manifest is rebuilt.

The asset is read from the bundle

AssetImage takes a path relative to the project root, exactly as written in pubspec.yaml. Flutter looks it up in the compiled asset bundle, so the apostrophe-free, lowercase, matching path is the whole contract.

!
Asset not found?

Check three things: the folder is at the project root, pubspec.yaml lists images/ with the correct indent, and you ran flutter pub get. After adding assets, a hot reload is not always enough — do a full restart.

i
Network vs. asset

Use network for content that changes and lives on a server. Use assets for logos, illustrations and anything that must work offline.

Container: the box you can style

Size, colour, padding, margin, border, radius — one widget covers them all.

A Container is a rectangular box around a child. It is the widget you reach for when something needs a background colour, a fixed size, rounded corners or breathing room.

Run itflutter run
9:41▮▮▮
Dashboard
Hello World
200 × 100 blue box
What happens

The box is pinned to the top-left

Scaffold.body gives its child the whole area under the app bar. The container is only 200 × 100, so the rest of the page stays empty. Its own Center places Hello World in the middle of the box — not the screen.

i
Two centres

A Center inside the container centres the text in the box. To centre the box itself, wrap the whole Container in a Center as well.

PropertyEffect
width / heightFixed size in logical pixels. Omit one and the box sizes to its child on that axis.
colorBackground fill. Shorthand for a BoxDecoration — you cannot use both at once.
padding / marginSpace inside the box around the child / space outside the box.
decorationColour, gradient, border, radius and shadow in one object. Replaces color.
childThe single widget inside. For several children use Row, Column or Stack.
!
An empty container grows

A Container with no child and no size expands to fill the space it is given. That is why removing width, height and the child turns the blue box into a full blue screen.

▶
Try it

Replace color: Colors.blue with decoration: BoxDecoration(color: Colors.blue, borderRadius: BorderRadius.circular(24)). Then add padding: EdgeInsets.all(20) and see how the text moves.

What happens

Vertical stack, horizontal group

The outer Column stacks the image above the Row. Inside the row, Icon, SizedBox and Text sit left to right, with 20 pixels of empty space between the icon and the label.

i
Why SizedBox?

Row has no gap property. A SizedBox(width: 20) is the idiomatic spacer; use SizedBox(height: 20) inside a Column.

Aligning along the main axis

A Column's main axis is vertical, a Row's is horizontal. mainAxisAlignment decides where the children sit along it.

The three icons pack at the top

start puts the first child at the beginning of the main axis and leaves all the leftover space at the end. Swap it for any value below without touching the children.

i
Cross axis

crossAxisAlignment works the other way: start, center, end or stretch across a Row's height or a Column's width.

!
Overflow stripes

If children are wider than the screen, Flutter paints yellow-and-black stripes and logs an overflow. Fix it with Expanded, Flexible or a smaller font — not by ignoring it.

▶
Try it

Change the three-icon column to MainAxisAlignment.spaceEvenly. Then wrap the Column in a Row with two more columns and watch the whole layout move.

Card: group content with depth

Colour, elevation, rounded corners and padding — the Material way to lift a block off the page.

A Card is a Material surface with a shadow and rounded corners. On its own it sizes to its child; add a SizedBox with double.infinity to stretch it across the screen. Each card below holds a picture on the left and a label on the right.

i
Why repeat the block?

Three cards are three separate widgets, so the code repeats. Later you will replace the repetition with a list and a loop — for now, seeing every widget spelled out makes the tree easier to read.

What happens

Every card is its own surface

The Column stacks the cards with their default margins. Inside each one, a Row with spaceBetween pushes the plane image to the left edge and the label to the right, while Padding keeps both away from the border.

i
Why double.infinity?

A card normally shrinks to fit its content. SizedBox(width: double.infinity) says "take every pixel the parent offers", so all three cards line up edge to edge.

i
The four properties

color paints the surface, elevation sets the shadow height, shape controls the corners, and child is the content — here a SizedBox wrapping Padding wrapping a Row.

▶

07

Your own launcher icon

Replace the default Flutter logo on the home screen with a picture of your own — on both Android and iOS.

Android and iOS each need the icon in a dozen sizes and formats. flutter_launcher_icons generates all of them from one square PNG.

1 · add the package→2 · configure pubspec→3 · generate→4 · stop & start the app
  1. Install the package from the project root with flutter pub add flutter_launcher_icons.
  2. Point it at your image. Add the flutter_launcher_icons: block to pubspec.yaml and run Pub get.
  3. Generate the icons from the terminal with dart run flutter_launcher_icons.
  4. Stop and start the app — q then flutter run. The launcher icon is cached by the OS, so a hot reload will not show it.

Legacy key

Older tutorials use flutter_icons: as the block name and flutter pub run flutter_launcher_icons:main as the command. Current versions expect flutter_launcher_icons: and dart run. 09

StatelessWidget: the screen that never changes

Put a button on screen, change a field in onPressed, and watch the UI ignore you.

Replace the green body with real content: a message and a button. The button updates a field called message. Run it, tap Subscribe, and read the console — the text on screen does not move. That is not a bug; it is what stateless means.

Run itflutter run
9:41▮▮▮
Dashboard
Please Subscribe
Tap it — nothing changes
What happens

The field changes. The pixels do not.

Pressing the button runs onPressed, prints the line, and assigns a new string to message. But build() is never called again, so Flutter keeps showing the old tree. Nothing tells the framework that the data it painted is stale.

i
Stateless ≠ no fields

A StatelessWidget may hold fields. What it lacks is a mechanism to say "my data changed, rebuild me". That mechanism is setState(), and it only exists on State.

!
Proof in the console

Every tap prints Inside onPressed. The handler runs every time — only the redraw is missing.

▶
Try it

Add print(message) after the assignment. The console shows the new value while the screen still shows the old one — the two are now out of sync. Keep this file; the next step fixes it.

10

StatefulWidget: make the tap visible

Same screen, one class change and one wrapper: setState() schedules a rebuild and the text updates.

A stateful widget is split in two: the widget (immutable configuration) and a State object that lives across rebuilds and holds the mutable data. createState() connects them.

Run itflutter run
9:41▮▮▮
Dashboard
Please Subscribe
Live demo — tap the button
What happens

One call, one rebuild

setState() runs your callback, marks the State object dirty, and asks Flutter to rebuild on the next frame. build() runs again, reads the new message, and the Text is replaced.

Debug Console — waiting for a tap
i
Two rules

Mutate state inside the setState callback, and never call setState() from build(). Each call schedules another frame.

StatelessWidget

Field changes, screen stays the same.

Use for static screens: layouts, labels, icons, anything whose data arrives from outside and never changes while visible.

StatefulWidget

setState() → rebuild → new pixels.

Use when the UI depends on something the user can change: counters, toggles, forms, data that loads after the first frame.

▶
Try it

Turn the button into a toggle: if the message is Please Subscribe, set it to Thank you for subscribing, otherwise set it back. One if inside setState is enough — no new widget needed.

Errors you will meet again

A RenderFlex overflowed by N pixels

A Row or Column is bigger than its parent. Wrap the flexible child in Expanded or Flexible, shrink the font, or add scrolling.

Unable to load asset

The path does not match, the folder is not declared under flutter: assets:, or you did not run flutter pub get after adding it.

The method 'setState' isn't defined

You called setState() inside a StatelessWidget. Convert it to a StatefulWidget and move the field into the State class.

Incorrect use of ParentDataWidget

Expanded or Flexible is outside a Row/Column, or a Positioned is outside a Stack. Move it to the correct parent.

setState() called during build

You called setState() while build() was running. Move it into a callback such as onPressed, or defer it with WidgetsBinding.instance.addPostFrameCallback().

No configuration found for flutter_launcher_icons

The block is missing from pubspec.yaml or is still named flutter_icons:. Rename it and re-run from the project root.
